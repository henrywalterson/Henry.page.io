Frenlit: AI-Powered Group Outing Planner

Role UX Research, UI Design
Project Graduation Project
Product type Web App

Overview

Hanging out offline with friends should feel fun and easy. But when everyone has different preferences, familiar places feel boring, and no one wants to decide, planning becomes tiring, especially for the host.

Problem

Group planning often feels repetitive and exhausting because finding fresh, group-fit places takes too much effort and usually falls on one person.

Solution

Frenlit collects everyone's preferences, suggests matching venues, and creates a shareable event card, with no app download or account required.

Design Process

Read the full UX research here.

Research

  • Find out why and how young people currently connect offline.
  • Interview 12 young people to know their motivations and difficulties when offline connecting.

Problem Defining

  • Use user journey to find out where the pain points are.
  • Create personas to specify user's goals, needs and pain points.
  • Make problem statement and how might we to discover solutions.

Solution Audit

  • Use how might we to find existed solutions.
  • Learn from those solutions and make a benchmark for ours.

Design Solution

  • Use crazy 8 method to generate and find ideas.
  • Find inspirations for design kit.
  • Design user flow, wireframe.
  • Refine and polish for mobile-first web app.

Design solution

UI Kit

Frenlit's UI kit includes five color scales: orange, green, blue, red, and grey. Key components include venue cards, tab bars, chips, join-code inputs, and event cards.

Branding & Visual Identity

Frenlit's brand feels warm, energetic, and approachable. The flame mascot represents the spark of a good plan, while the orange-led color palette keeps the product playful and friendly. SF Pro Rounded is used for headlines and SF Pro for body text, ensuring a consistent mobile web experience.

AI Planning Flow

The core flow is a 4-step questionnaire that collects each person's preferences: time, location, vibe, and group members. The AI then combines the inputs and suggests the best matching venues.

Plan Results & Group Deals

Frenlit shows ranked venue results with match percentage, rating, distance, opening hours, capacity, and price range. Group deals are highlighted, and users can call, reserve, or get directions directly.

Event Card & Group Code

Once a plan is confirmed, Frenlit creates a shareable event card with a QR code and short join code. Anyone can join by scanning or entering the code, without creating an account.

Location Library

Frenlit also includes a browseable library with Nearby, Group Deal, and Routes tabs. Routes are curated multi-stop experiences that groups can follow together.

Room for Innovation

Responsive Expansion

Expand Frenlit to tablet and desktop for easier planning on larger screens.

Archive Mode

Allow groups to save past hangouts, photos, and shared stats as social memories.

Activity Library

Add prompts, mini games, and group challenges to make hangouts more engaging.
